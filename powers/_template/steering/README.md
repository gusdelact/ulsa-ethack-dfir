# steering/ — guías de conocimiento cargables bajo demanda

> Esqueleto reutilizable del modelo estándar de Power.

Coloca aquí las guías de conocimiento del Power como archivos `*.md` que Kiro
carga **bajo demanda** (divulgación progresiva): una guía por fase, servicio o
tema. No cargues todo de golpe; referencia cada guía desde `skills/<skill>/SKILL.md`
y deja que se lean solo cuando la tarea lo requiera.

Convención sugerida de nombres: `<tema>.md` (p. ej. `nmap-descubrimiento-hosts.md`,
`metodologia-flujo.md`). Borra este README al añadir tus guías reales.
