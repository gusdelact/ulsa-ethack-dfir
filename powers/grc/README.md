# `powers/grc/` — Powers de GRC (alumno)

Powers **nuevos o extendidos** del Responsable de GRC (1 alumno), en layout de dos niveles `powers/grc/<power>/`.

**Cimiento existente** (vive en `powers/grc-nist-csf/`, un nivel; **no recrear**): `grc-nist-csf` guía la gobernanza, el riesgo y el cumplimiento usando **NIST CSF 2.0** como eje (risk register, gap analysis, POA&M, LFPDPPP↔CIS). Los hallazgos técnicos de Red/Blue/DF se vinculan a subcategorías CSF como evidencia.

_Referencias: Req 6.5, 19.1, 9.4, 13.1._
